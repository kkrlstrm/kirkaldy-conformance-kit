# Change log: probes, controls and verdict rules (spec §3.10)

Every change to a probe, a control or a verdict rule made after a run against any target is
entered here with its reason and the run that prompted it (spec §3.10, rule 1). It applies to
every target. Where the run that prompted it is still inside a disclosure window (spec §6), the
target is named once that result is published. Changes to a single property's probe are also
logged in that property's interface file (for P21, `docs/KRK21-INTERFACE.md`).

Entries are in the order they were made. The version digests of this copy of the kit differ from
those of the tree each change was first made in, so the Versions column says which versions
moved, not their values. Run `python -m conformance known-bad --status` for this tree's own.
