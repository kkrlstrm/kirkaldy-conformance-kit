# Operations v3: Company requirement coverage

This is a working coverage map for [Operations v3](https://github.com/personal-agent-protocol/personal-agent-protocol/blob/85b41ff27e8f6a098d06b71f14d83b1513c728a5/content/versions/1.0/extensions/operations.mdx), at commit `85b41ff27e8f6a098d06b71f14d83b1513c728a5`. Each row describes an applicable interface or condition. A response check alone cannot prove the absence of an effect. The official validator's [README](https://github.com/personal-agent-protocol/personal-agent-protocol/blob/85b41ff27e8f6a098d06b71f14d83b1513c728a5/kit/company/validate/README.md) says its Extensions milestone checks only what a run declaring no extensions sees. The “No” entries refer to the operation behavior in each row, not to all foundation checks.
